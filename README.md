# TxtIntr

Калькулятор с операциями арксинуса и арккосинуса (вар10).

## Возможности
- `asin` — арксинус
- `acos` — арккосинус
- Поддержка режимов: радианы (`rad`) и градусы (`deg`)

## Сборка
cd calculator
make

## Использование
./calculator -o asin 0.5
./calculator -o acos -m deg 0.5

## Пример вывода
$ ./calculator -o asin -m deg 0.5
30
